# Association app for Android

The Android app of the Association Platform: membership, elections, polls, meetings, groups and confidential complaints for residents' and employees' associations.

## Download

**[Download the newest version](https://github.com/assocplatform/association-app/releases/latest/download/association-app.apk)** (APK file, about 20 MB, Android 7.0 or newer)

**Older phone?** If your phone says the app is not compatible, download the file ending in `-older-phones.apk` from the newest release on the [Releases](https://github.com/assocplatform/association-app/releases) page instead, and keep using that kind of file for updates.

All versions and what changed: [Releases](https://github.com/assocplatform/association-app/releases)

## Install

1. Open the download link on your Android phone.
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for your browser or Files app, go back and tap **Install**.
3. Sign in with the account you use for your association, or create one with your association's joining code.

Android may show a Play Protect message because the app is installed from outside the Play Store.

## Update

Download the newest version and install it over the old one. Your account and data are kept on the server.

## No Android phone?

Use the same account on the website: <https://assocplatform.vercel.app>. You can add it to your phone's home screen from the browser menu.

## Check the file (optional)

Each release includes a `.sha256` file with the checksums of the APK files.
